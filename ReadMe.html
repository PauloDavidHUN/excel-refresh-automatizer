⚡ Excel Refresh Automatizer

Automatically opens Excel workbooks, refreshes all data connections and pivot tables, saves the result, and closes — fully unattended. Supports Box sync detection and Windows Task Scheduler integration.

✨ What it does

🔄
Connection Refresh
Refreshes all OLEDB data connections with background query disabled for reliability.
📊
Pivot Table Refresh
Iterates every sheet and refreshes all pivot tables automatically.
📦
Box Sync Aware
Waits for Box file sync to complete before opening — no corrupt reads.
🕒
Task Scheduler Ready
Runs automatically on schedule via Windows Task Scheduler — no manual steps needed.
📝
Detailed Logging
Logs every step to console and refresh.log with timestamps.
⚙️
Easy Config
Add or remove Excel files in a single config.py — no code changes needed.

📋 Requirements

  • Python 3.x — tested on 3.10+
  • Windows OS — uses Win32 COM to control Excel
  • Microsoft Excel — must be installed
  • pywin32 — see requirements.txt

🔍 How it works

  1. Reads the file list from config.py
  2. Waits for Box cloud sync to finish (size-stability check)
  3. Opens the workbook silently via Win32 COM
  4. Disables background queries, then refreshes all connections
  5. Waits for all background queries to finish
  6. Refreshes every pivot table on every sheet
  7. Saves and closes — Excel exits cleanly

🗓️ Task Scheduler How-To

Follow these steps to set up an automated schedule in Windows Task Scheduler so the script runs without any manual intervention.

1
Open Task Scheduler
Press Win + S, search for Task Scheduler and open it. Then click Create Task… in the right-hand Actions panel.
2
General tab
Fill in the fields as described in the table below.
3
Triggers tab
Click New… and set when the task should run (e.g. Daily at 06:00). See the table below for details.
4
Actions tab
Click New… and point it to your Python executable and script. See the table below for the exact values.
5
Conditions tab
Optionally uncheck "Start the task only if the computer is on AC power" if you want it to run on battery too.
6
Settings tab
Enable "Run task as soon as possible after a scheduled start is missed" so it catches up after a reboot or sleep.
Tab Field What to enter
General Name e.g. Excel Refresh Automatizer
General Description e.g. Auto-refreshes Excel workbooks daily
General Security options Select "Run whether user is logged on or not" + check "Run with highest privileges"
Triggers Begin the task On a schedule
Triggers Settings Daily — set your preferred start time (e.g. 06:00:00)
Triggers Recur every 1 day
Actions Action Start a program
Actions Program/script Full path to your Python executable, e.g. C:\Python310\python.exe — find it with where python in CMD
Actions Add arguments refresh_starter.py
Actions Start in Full path to the project folder, e.g. C:\Users\YourName\excel-refresh-automatizer
Conditions Power Uncheck "Start only if on AC power" if needed
Settings If missed Enable "Run task as soon as possible after a scheduled start is missed"
Settings If already running Select "Do not start a new instance"
💡

To find your Python path quickly, open Command Prompt and run where python. Copy the full path shown and paste it into the Program/script field.

⚠️

Make sure the Start in field is set correctly — without it, Python won't find config.py and the script will fail silently.
